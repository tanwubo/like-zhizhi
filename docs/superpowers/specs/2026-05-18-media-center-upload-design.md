# 媒体中心上传优化设计

## 概述

优化后台"媒体中心"模块，支持多选上传（最多10个文件）、文件拖拽上传，并将文件大小限制从 10MB 调整到 20MB。媒体列表从表格改为网格卡片展示。

## 需求汇总

| 项目     | 现状                        | 目标            |
| ------ | ------------------------- | ------------- |
| 文件大小限制 | 10MB                      | 20MB          |
| 上传方式   | 单文件 `<input type="file">` | 多选 + 拖拽上传     |
| 多选数量   | 不支持                       | 最多 10 个       |
| 上传交互   | 提交表单自动上传                  | 手动点击上传按钮      |
| 上传进度   | 无                         | 不显示进度，完成后统一提示 |
| 媒体列表   | 表格                        | 网格卡片          |

## 技术方案

选用 **react-dropzone** 处理拖拽和多选逻辑，保持现有 Server Actions 架构不变。

### 选择理由

- react-dropzone 是拖拽上传领域的事实标准（24k+ stars），仅 15KB gzipped
- 专注拖拽和文件选择，不绑定上传逻辑，与现有 Server Actions 完美配合
- 不引入重型上传组件库（如 Uppy/FilePond），避免过度设计

## 架构变更

### 页面拆分

当前 `page.tsx` 是纯 Server Component，改造为 Server + Client 混合：

- `page.tsx`（Server Component）：保持数据获取，传递 assets 给客户端组件
- `MediaUploader`（Client Component）：处理拖拽、多选、文件列表、上传调用
- `MediaGrid`（Client Component）：网格卡片展示媒体列表

### 上传逻辑改造

`uploadMediaAsset` Server Action 保持单文件接口不变，改造点：

1. 移除末尾 `redirect`，改为返回 `{ ok: true } | { ok: false; error: string }`
2. 客户端循环调用该 action，每个文件独立 FormData
3. 全部完成后 `router.refresh()` 刷新列表

### 大小限制调整

- `next.config.ts`：`bodySizeLimit` 从 `"10mb"` 改为 `"20mb"`
- 客户端：添加 20MB 前端校验，超限文件直接提示，不加入待上传列表

## 组件设计

### MediaUploader

```
┌─────────────────────────────────────────────┐
│  上传文件                                     │
│  使用已配置的 S3 兼容对象存储                    │
├─────────────────────────────────────────────┤
│                                             │
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐  │
│  │  📂  拖拽文件到此处上传                    │  │
│  │     或点击选择文件                        │  │
│  │     最多10个，单文件≤20MB                 │  │
│  └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘  │
│                                             │
│  已选文件（3个）                              │
│  ┌─────────────────────────────────────────┐│
│  │ 🖼️ photo-001.jpg    2.3 MB        ✕   ││
│  │ 🎵 audio-clip.mp3    4.1 MB        ✕   ││
│  │ 📄 document.pdf      1.8 MB        ✕   ││
│  └─────────────────────────────────────────┘│
│                                             │
│  ⚠️ video-large.mp4 超过20MB限制，已跳过      │
│                                             │
│                          [上传媒体]          │
└─────────────────────────────────────────────┘
```

- 拖拽区域：react-dropzone 的 `useDropzone` hook，虚线边框，拖入时高亮
- 文件列表：显示文件名、大小、类型图标，右侧删除按钮
- 校验提示：超限/超数文件在列表下方显示警告，不加入待上传列表
- 上传按钮：点击后逐个调用 `uploadMediaAsset`，按钮显示"上传中..."
- 结果提示：全部成功显示"上传成功"，有失败显示"X个文件上传失败"

### MediaGrid

```
┌─────────────────────────────────────────────────────────┐
│  媒体列表                                                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐     │
│  │ 🖼️   │  │ 🖼️   │  │ 🎵   │  │ 🎬   │  │ 📄   │     │
│  │      │  │      │  │      │  │      │  │      │     │
│  ├──────┤  ├──────┤  ├──────┤  ├──────┤  ├──────┤     │
│  │photo │  │banner│  │audio │  │clip  │  │doc   │     │
│  │001   │  │002   │  │003   │  │004   │  │005   │     │
│  │2.3MB │  │5.1MB │  │4.1MB │  │8.2MB │  │1.8MB │     │
│  │图片   │  │图片   │  │音频   │  │视频   │  │文件   │     │
│  └──────┘  └──────┘  └──────┘  └──────┘  └──────┘     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

- 布局：响应式网格 `grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5`
- 卡片内容：
  - 顶部预览区：图片类型显示缩略图（`next/image`），其他类型显示对应图标 + 文件扩展名
  - 底部信息区：文件名（单行截断）、文件大小、媒体类型标签（Badge）
- 交互：点击卡片在新标签页打开 `publicUrl`
- 空状态：无媒体时显示"暂无媒体，先上传文件或登记一个外部地址"

### 外部媒体登记

保持现有 `AdminActionForm` 不变，无改动。
